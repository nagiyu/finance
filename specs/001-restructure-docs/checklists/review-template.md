## 正確性チェック

- [ ] ドキュメントの内容が最新のコードと一致している
- [ ] 記載されている手順が実際に動作する
- [ ] コードパスへの参照（`related-code-paths`）が有効である
- [ ] 外部リンクが有効である
- [ ] 技術的な情報が正確である

## 完全性チェック

- [ ] 必須フィールド（title, area, topic, owner, last-updated, status）が記載されている
- [ ] 目的セクションが明確に記述されている
- [ ] 前提条件が網羅されている
- [ ] 手順が完全で理解しやすい
- [ ] テスト/検証方法が記載されている

## 構造と形式チェック

- [ ] フロントマターが正しい形式で記載されている
- [ ] Markdown の構文が正しい
- [ ] 見出しの階層が適切である
- [ ] コードブロックが正しくフォーマットされている
- [ ] ドキュメントが適切な場所に配置されている

## 最新性チェック

- [ ] `last-updated` フィールドが最終更新日と一致している
- [ ] 最終更新から 3 ヶ月以上経過していないか確認
- [ ] 関連するコード変更がドキュメントに反映されている
- [ ] 廃止された機能や API への言及がないか確認
