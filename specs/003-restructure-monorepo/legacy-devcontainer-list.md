## 詳細分析

### 1. `template/client/.devcontainer/`

- **devcontainer.json**: `sample` という名前で、サンプルプロジェクト用のテンプレート
- **Dockerfile**: `node:20` ベースのシンプルな定義
- **推奨**: テンプレートディレクトリ自体の用途を確認し、不要であれば `template/` ディレクトリごと削除を検討

### 2. `server/finance/.devcontainer/`

- **devcontainer.json**: AWS Lambda 用の開発環境設定
- **Dockerfile**: `public.ecr.aws/lambda/nodejs:22` ベースで、Lambda 開発に特化
- **推奨**: サーバー開発用に `.devcontainer/server/devcontainer.json` を新規作成し、この設定を移行後に削除。Lambda 特有の設定は移行先で維持すること。

### 3. `client/finance/.devcontainer/`

- **devcontainer.json**: `node:20` イメージを使用したクライアント開発環境
- **Dockerfile**: `node:20` ベースで `repomix` をインストール
- **推奨**: ルート直下の `.devcontainer/client/devcontainer.json` が既に存在するため削除。必要な設定（repomix など）があればルート側に統合。

### 4. `finance/.devcontainer/`

- **devcontainer.json**: `node:20` ベースの finance モジュール開発環境
- **Dockerfile**: `node:20` ベースのシンプルな定義
- **推奨**: ルート直下の `.devcontainer/finance/devcontainer.json` が既に存在するため削除。
