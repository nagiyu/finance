# 権限マトリックス テストガイド

## 概要

このドキュメントは、権限マトリクスのキャッシュ管理機能が正しく動作することを確認するためのテストガイドです。

## 前提条件

- 管理者アカウントでログインできること
- `/permission-admin` にアクセスできること
- 複数のブラウザまたはプライベートウィンドウを使用できること

## テストケース

### テストケース 1: 権限マトリックスの更新が保存される

**目的**: 権限マトリックスを更新した際、DBに正しく保存されることを確認

**手順**:
1. 管理者アカウントでログイン
2. `/permission-admin` にアクセス
3. 任意の機能（例: STOCK_CHART）のゲスト権限を「アクセス不可」から「閲覧のみ」に変更
4. 「保存」ボタンをクリック
5. 成功メッセージが表示されることを確認
6. ページをリロード（F5）
7. 変更した権限設定が保持されていることを確認

**期待結果**:
- リロード後も権限設定が「閲覧のみ」のまま
- 古い状態（「アクセス不可」）に戻らない

**確認ポイント**:
- [x] 保存成功メッセージが表示される
- [x] リロード後も設定が保持される

---

### テストケース 2: 権限変更がゲストユーザーに反映される

**目的**: 権限マトリックスを更新した際、ゲストユーザーのアクセス権限が即座に変更されることを確認

**初期設定**:
- STOCK_CHART のゲスト権限: NONE（アクセス不可）

**手順**:
1. **別ウィンドウ（プライベートモード）でゲストとしてアクセス**
   - ログインせずに `/` にアクセス
   - 株価チャートが表示されないことを確認（権限エラー）

2. **管理者ウィンドウで権限を変更**
   - `/permission-admin` にアクセス
   - STOCK_CHART のゲスト権限を「アクセス不可」→「閲覧のみ」に変更
   - 「保存」ボタンをクリック

3. **ゲストウィンドウで再確認**
   - ページをリロード（F5）またはハードリロード（Ctrl+Shift+R）
   - 株価チャートが表示されることを確認

**期待結果**:
- 権限変更前: ゲストは株価チャートにアクセスできない
- 権限変更後: ゲストは株価チャートを閲覧できる

**確認ポイント**:
- [x] 権限変更前はアクセス拒否される
- [x] 権限変更後はアクセス可能になる
- [x] リロード後すぐに反映される

---

### テストケース 3: サーバー側キャッシュの動作確認

**目的**: サーバー側のキャッシュが正しく動作し、更新時にクリアされることを確認

**手順**:
1. ブラウザの開発者ツールを開く（F12）
2. Consoleタブで以下のコマンドを実行して権限チェック
   ```javascript
   fetch('/api/auth/check-permission', {
     method: 'POST',
     headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify({ feature: 'stockChart', level: 'view' })
   }).then(r => r.json()).then(console.log)
   ```
3. レスポンスのタイムスタンプを記録
4. 同じリクエストを数回実行（5分以内）
5. `/permission-admin` で権限を変更
6. 再度同じリクエストを実行
7. 変更後の権限が即座に反映されることを確認

**期待結果**:
- 権限変更前: 同じ結果が返される（キャッシュから）
- 権限変更後: 新しい権限が即座に反映される（キャッシュがクリアされた）

**確認ポイント**:
- [x] キャッシュが動作している（同じ結果が返る）
- [x] 更新時にキャッシュがクリアされる
- [x] 5分以内に再取得してもキャッシュが有効

---

### テストケース 4: クライアント側キャッシュの無効化

**目的**: ブラウザがAPIレスポンスをキャッシュしないことを確認

**手順**:
1. ブラウザの開発者ツールを開く（F12）
2. Networkタブを開く
3. `/permission-admin` にアクセス
4. ネットワークリクエストで `/api/permission-matrix` を探す
5. レスポンスヘッダーを確認

**期待結果**:
以下のヘッダーが設定されている:
```
Cache-Control: no-store, no-cache, must-revalidate, proxy-revalidate
Pragma: no-cache
Expires: 0
```

**確認ポイント**:
- [x] Cache-Control ヘッダーが正しく設定されている
- [x] Pragma ヘッダーが設定されている
- [x] Expires ヘッダーが設定されている

---

### テストケース 5: 複数機能の権限を同時に変更

**目的**: 複数の機能の権限を同時に変更しても正しく保存されることを確認

**手順**:
1. `/permission-admin` にアクセス
2. 以下の権限を変更（保存しない）:
   - STOCK_CHART のゲスト権限: NONE → VIEW
   - EXCHANGE のゲスト権限: NONE → VIEW
   - TICKER のゲスト権限: NONE → VIEW
3. 「保存」ボタンをクリック
4. ページをリロード
5. すべての変更が保持されていることを確認

**期待結果**:
- すべての変更が同時に保存される
- リロード後もすべての変更が保持される

**確認ポイント**:
- [x] 複数の変更が同時に保存される
- [x] リロード後もすべての変更が保持される

## パフォーマンステスト

### パフォーマンステスト 1: キャッシュによる高速化

**目的**: キャッシュによってパフォーマンスが向上することを確認

**手順**:
1. ブラウザの開発者ツールを開く（F12）
2. Networkタブを開く
3. ページをリロード（F5）
4. `/api/auth/check-permission` のレスポンス時間を記録
5. 5分以内に再度リロード
6. レスポンス時間を比較

**期待結果**:
- 初回: 数十～数百ミリ秒（DB アクセス）
- 2回目以降（5分以内）: より高速（キャッシュから）

**確認ポイント**:
- [x] 2回目以降のレスポンスが高速
- [x] 5分経過後は再度DBアクセス

## トラブルシューティング

### 問題: 権限が反映されない

**原因**: ブラウザキャッシュが残っている可能性

**解決方法**:
1. ハードリロード（Ctrl+Shift+R または Cmd+Shift+R）を実行
2. ブラウザの開発者ツールで「Disable cache」を有効化
3. プライベートウィンドウで確認

---

### 問題: 保存後もリロードすると古い状態に戻る

**原因**: DB保存に失敗している可能性

**解決方法**:
1. ブラウザの開発者ツール → Consoleタブでエラーを確認
2. Networkタブで `/api/permission-matrix` のレスポンスを確認
3. サーバーログを確認

---

## 自動テストスクリプト（参考）

ブラウザのコンソールで実行できるテストスクリプト:

```javascript
// 権限チェックテスト
async function testPermissionCheck(feature, level) {
  const response = await fetch('/api/auth/check-permission', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ feature, level }),
    cache: 'no-store'
  });
  const result = await response.json();
  console.log(`Feature: ${feature}, Level: ${level}, Has Permission: ${result.hasPermission}`);
  return result.hasPermission;
}

// テスト実行
async function runTests() {
  console.log('=== Permission Check Tests ===');
  await testPermissionCheck('stockChart', 'view');
  await testPermissionCheck('exchange', 'view');
  await testPermissionCheck('ticker', 'view');
  console.log('=== Tests Complete ===');
}

// 実行
runTests();
```
